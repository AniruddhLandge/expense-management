# Expense Management System

A user-friendly web application designed to help users manage their personal finances by tracking income and expenses in one place. It allows users to monitor their spending habits, organize transactions, and maintain better control over their budgets.

## 🚀 Features

- **Add Transactions:** Easily add income and expense records.
- **Manage Transactions:** Update and delete existing transactions.
- **Expense Tracking:** Keep track of daily expenses and income.
- **Category Management:** Organize transactions into different categories.
- **Financial Overview:** Get a clear overview of your income, expenses, and available balance.
- **User-Friendly Interface:** Simple and responsive design for easy navigation.

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Tools:** Git, GitHub, VS Code

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/AniruddhLandge/expense-management
```

### 2. Navigate to the Project Directory

```bash
cd Expense-Management-System
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Start the Frontend

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

### 5. Start the Backend

Open another terminal:

```bash
cd server
npm install
npm start
```
## 🎯 Project Objective

The main objective of this project is to make personal expense management easier and more organized. It helps users understand where their money is going, track their financial activities, and make better financial decisions.
